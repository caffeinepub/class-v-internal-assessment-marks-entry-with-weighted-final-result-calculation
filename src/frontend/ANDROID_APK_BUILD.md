# Android APK Build Guide

This guide explains how to build debug and release APK files for the Class V Assessment System Android app using Capacitor.

## Prerequisites

Before building the Android app, ensure you have the following installed:

1. **Node.js** (v18 or higher)
2. **pnpm** package manager
3. **Android Studio** (latest stable version)
   - Download from: https://developer.android.com/studio
4. **Android SDK** (API Level 34 or higher)
   - Install via Android Studio SDK Manager
5. **Java Development Kit (JDK)** 17
   - Can be installed via Android Studio or separately
6. **Capacitor CLI**
   ```bash
   npm install -g @capacitor/cli
   ```
